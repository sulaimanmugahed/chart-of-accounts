# واجهة دليل الحسابات | Chart of Accounts UI

واجهة عربية (RTL) لإدارة دليل الحسابات مبنية على **React 19 + Vite + TypeScript**، وتعمل فوق خدمة
`ChartOfAccounts` (.NET) الموجودة في هذا المستودع.

| التقنية | الاستخدام |
| --- | --- |
| **TanStack Query v5** | كل حالة الخادم: الجلب، التخزين المؤقت، الإبطال بعد كل تعديل، الطفرات (Mutations). |
| **TanStack Table v9** | جداول البيانات: شجرة الحسابات، الجدول المسطّح، عُقد القوالب، سجلات التدقيق، جداول الشركات والمهام النظامية. |
| **React Hook Form + Zod** | جميع النماذج مع تحقق عربي موحّد. |
| **Tailwind CSS v4** | نظام التصميم (CSS-first عبر `@theme`) مع مكوّنات واجهة محلية. |
| **React Router 7** | التنقل بين الصفحات. |

## التشغيل السريع

```bash
cd frontend
npm install
npm run dev        # http://localhost:5173
```

### أوضاع التشغيل: محاكاة (افتراضي) / الخدمة الحقيقية

الوضع الافتراضي هو **mock**: يعمل الخادم البرمجي الوهمي داخل سيرفر Vite نفسه
(`mock/vite-plugin.ts` + `mock/handlers.ts`) ويحاكي كامل واجهة REST للخدمة — نفس المسارات،
نفس رموز الأخطاء، ونفس قواعد العمل (حدود العمق، القوالب المعيارية، القفل، التدقيق…).
لذلك يمكن عرض الواجهة وتجربتها **دون تشغيل خدمة .NET**.

لتوجيه الواجهة إلى الخدمة الفعلية:

```bash
# تشغيل خدمة .NET على المنفذ 5126 ثم:
VITE_API_MODE=real npm run dev                       # يستهدف http://localhost:5126
VITE_API_MODE=real VITE_API_TARGET=http://host:port npm run dev   # هدف مخصص
```

في وضع `real` يُمرَّر `/api` و`/ping` عبر وكل Vite إلى الخدمة الفعلية، ولا يُحمَّل خادم المحاكاة.

## الأوامر

| الأمر | الوصف |
| --- | --- |
| `npm run dev` | سيرفر التطوير مع HMR (واجهة المحاكاة مضمّنة). |
| `npm run build` | فحص الأنواع (`tsc -b`) ثم بناء الإنتاج إلى `dist/`. |
| `npm run preview` | معاينة حزمة الإنتاج (واجهة المحاكاة تعمل هنا أيضًا). |
| `npm run typecheck` | فحص الأنواع فقط. |
| `npm run smoke` | اختبار دخان شامل: يرسم كل الصفحات على الخادم (SSR) مقابل واجهة المحاكاة، ثم يمرّ على تدفقات API كاملة (تهيئة، حدود عمق، أدوار، حذف، قفل). |
| `npm run lint` | Oxlint. |

## الصفحات

| المسار | الوصف |
| --- | --- |
| `/` | لوحة المتابعة: إحصاءات، توزيع الحسابات، الأدوار الحرجة، آخر عملية تهيئة. |
| `/companies` | قائمة الشركات، إنشاء/تعديل، ضبط حد العمق، ومؤشر التهيئة. |
| `/templates` | القوالب المعيارية (IFRS التجاري، الخدمات المهنية، المنشآت الصغيرة) مع عرض شجرتها. |
| `/accounts` | شجرة دليل الحسابات (قابلة للطي) + عرض مسطّح بترشيح وترتيب، وإنشاء/تعديل/حذف الحسابات. |
| `/initialization` | محرك التهيئة: فحص مسبق (Validate) ثم تهيئة بأحد الأوضاع الثلاثة (صارم / دمج آمن / محاكاة) + سجل التدقيق. |
| `/system-accounts` | ربط الأدوار النظامية بالحسابات، مع فحص الأدوار الحرجة وقفل/كسر القفل. |

## بنية المشروع

```
frontend/
├── mock/                 # واجهة المحاكاة (بيانات + موجّه + إضافة Vite)
│   ├── types.ts          #   أشكال جداول المحاكاة
│   ├── seed.ts           #   البيانات الأولية (3 شركات، 3 قوالب، شجرة حسابات كاملة)
│   ├── handlers.ts       #   موجّه REST يحاكي Controllers وقواعد العمل
│   └── vite-plugin.ts    #   ربط المحاكاة بسيرفر التطوير والمعاينة
├── scripts/              # اختبار الدخان (رسم SSR + تدفقات API)
└── src/
    ├── api/              # الأنواع، التعدادات، عملاء REST لكل مورد (TanStack Query)
    ├── components/       # نظام التصميم: ui / layout / data / feedback
    ├── features/         # صفحات المزايا: companies, templates, accounts, initialization, system-accounts, dashboard
    ├── hooks/            # الشركة المختارة (سياق عام محفوظ في localStorage)
    ├── lib/              # fetch wrapper، الأخطاء، التنسيق العربي، تهيئة QueryClient
    └── styles/           # Tailwind v4 theme + الأنماط العامة
```

## ملاحظات

- **الشركة المختارة** سياق عام يُحفظ في `localStorage`، وتُبنى عليه كل الشاشات (الشجرة، الأدوار، التهيئة).
- الأخطاء القادمة من الخدمة (`ExceptionHandlingMiddleware`) تُترجم إلى رسائل عربية وإلى أخطاء حقول
  مباشرة في النماذج عبر `setError`.
- واجهة المحاكاة غير مضمّنة في حزمة الإنتاج إلا كمُضيف لسيرفر المعاينة؛ لا تُرسل أي طلبات لجهات خارجية.
